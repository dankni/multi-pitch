About this application

A counter for a session at the bouldering wall. Tap a grade each time you top one out and it keeps the tally; the minus beside it takes one back. Saving keeps the count, the hardest grade, a rating and a note. Everything is stored on this device only – nothing is uploaded anywhere.

The ladder stops at V10, which covers most nights. HARDER adds the next grade up for this session only – the next one starts back at V10.

The wrench beside a saved session reopens it, so a session can be added to or corrected later.
