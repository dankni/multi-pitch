About this application

A stopwatch for lap training. Start the clock, then tap LAP every time you finish a circuit, a set on the bouldering wall or a lap on a route. It keeps the total time and the number of laps – nothing else to fiddle with.

Pause and start again as often as you like – the clock only counts while it is running. Sessions are saved on this device only, nothing is uploaded anywhere. Press the space bar to lap and Escape to pause if you have a keyboard.
